# Rock-paper-scissor-game

A simple and fun **Rock Paper Scissors game** built using **Python and Flask**. The player can choose Rock, Paper, or Scissors and play against other player on same page.

## Features

* Simple and user-friendly interface
* Play against a real human
* Shows both choices and game result
* Keeps the game easy and interactive

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository and open the project folder.
2. Activate the virtual environment.
3. Install the required packages.
4. Run the Flask application:

```bash
python main.py
```

5. Open `http://127.0.0.1:5000/` in your browser.
